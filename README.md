# Diabetes Prediction

This project predicts whether a person has diabetes using health data.  
It uses a dataset called **BRFSS 2015** and applies machine learning models.
# Diabetes
The Diabetes Health Indicators Dataset contains healthcare statistics and lifestyle survey information about people in general along with their diagnosis of diabetes

## What this project does
- Reads the dataset
- Shows basic information and graphs
- Trains three models:
  - Logistic Regression
  - Random Forest
  - Xgboost
- Compares their accuracy

## How to run
1. Open the file **Diabetes.ipynb** in Jupyter Notebook.
2. Run each cell one by one.
3. You will see:
   - Dataset summary
   - Graphs
   - Model results (accuracy and reports)
